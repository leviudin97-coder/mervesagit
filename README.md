# MerveSagit — Artist Website

A responsive artist portfolio prototype using original artwork and the Merve Sagit logo.

## Preview

https://merve-sagit-art-studio.leviudin.chatgpt.site/

## Run locally

Open `index.html` in a browser, or run `python3 -m http.server 8000` from the repository root and visit http://localhost:8000.

No build step or dependencies are required. Includes gallery filters, a keyboard-accessible artwork lightbox, scroll reveals, hero motion, and reduced-motion support.

The enquiry form is a demonstration and does not send or store submissions. Artwork captions are descriptive placeholders. Artwork and branding belong to their respective owner.
